# Proyecto DSI

Proyecto de vistas web para clase, elaborado con HTML, CSS, JavaScript y Bootstrap 5.

## Páginas
- `index.html`: inicio.
- `login.html`: formulario visual de acceso.
- `admin/index.html`: panel de administrador con menú lateral.

## Cómo verlo
Abre `index.html` en tu navegador o utiliza la extensión Live Server de Visual Studio Code. Se necesita conexión a Internet para cargar Bootstrap desde CDN.

El formulario de acceso lleva al panel solo como demostración; **no implementa autenticación** ni base de datos.
