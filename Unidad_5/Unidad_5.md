### **1. Comunicación**

Es la etapa donde se habla con el cliente o las personas que necesitan el software para saber qué es lo que quieren. Aquí se identifican sus necesidades, los problemas que buscan resolver y las funciones que debe tener el programa.

### **2. Planeación**

Consiste en organizar cómo se va a realizar el proyecto. Se establecen las actividades, los tiempos, los recursos necesarios y las responsabilidades de cada integrante para llevar un mejor control del trabajo.

### **3. Modelado**

En esta etapa se diseña cómo va a funcionar el software antes de comenzar a programarlo. Se pueden utilizar diagramas, esquemas o diseños para representar su estructura, sus pantallas y la manera en que se relacionan sus diferentes partes.

### **4. Construcción**

Es cuando se empieza a crear el software mediante la programación. Se escribe el código y se realizan pruebas para comprobar que las funciones trabajen correctamente y corregir los errores que puedan aparecer.

### **5. Despliegue**

Es la etapa en la que el software ya terminado se instala o se pone a disposición de los usuarios. También se revisa que funcione bien en el lugar donde será utilizado y se pueden hacer mejoras según las opiniones de las personas.
